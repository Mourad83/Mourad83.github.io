Renault Morocco
Automotive Sales Dashboard

An end-to-end Power BI project focused on automotive sales performance in Morocco. The report covers commercial performance, targets, profitability, inventory and KPI documentation.

Main toolPower BI
Data preparationPower Query M
CalculationsDAX
DomainSales · Profitability · Inventory

Project context

Business need

Create a single decision-making view to analyse sales, revenue, margin, discounts, commercial targets and inventory availability by period, region, dealership and model.

BI approach

Build an analytical Power BI model with data preparation, DAX measures, consistent business filters, multi-page navigation and centralised KPI documentation.

Technical highlights

Data model & calculations

Commercially oriented data model with DAX measures for sales, margins, discounts, targets and variances, plus analysis by year, month, region, dealership and model.

User experience & analysis

Six business pages, global filter reset, regional and sales-representative analysis, and dynamic KPI documentation including DAX formulas.
